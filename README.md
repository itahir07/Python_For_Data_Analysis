# 🐍 Python for Data Analysis

> A structured, progressive learning path from Python fundamentals to data visualization — designed as a hands-on reference for data analysis.

## 📚 Curriculum Overview

This repository is organized into **4 progressive modules**, taking you from core Python concepts to professional data analysis and visualization.

### Module 1 — Python Fundamentals
| Topic | Description |
|-------|-------------|
| [Variables & Operators](01-fundamentals/variables-and-operators/) | Data types, arithmetic, comparison & logical operators |
| [Strings](01-fundamentals/strings/) | String manipulation, formatting, and methods |
| [Conditional Statements](01-fundamentals/conditional-statements/) | if/elif/else logic and decision making |
| [Loops](01-fundamentals/loops/) | for loops, while loops, and iteration patterns |
| [Built-in Functions](01-fundamentals/builtin-functions/) | Essential Python built-in functions |

### Module 2 — Data Structures
| Topic | Description |
|-------|-------------|
| [Lists](02-data-structures/lists/) | List operations, comprehensions, and methods |
| [Tuples](02-data-structures/tuples/) | Immutable sequences and tuple operations |
| [Sets](02-data-structures/sets/) | Set theory operations and unique collections |
| [Dictionaries](02-data-structures/dictionaries/) | Key-value pairs and dictionary methods |
| [User-Defined Functions](02-data-structures/user-defined-functions/) | Function creation, parameters, and returns |

### Module 3 — Data Analysis
| Topic | Description |
|-------|-------------|
| [NumPy](03-data-analysis/numpy/) | Numerical computing, arrays, and mathematical operations |
| [Pandas](03-data-analysis/pandas/) | DataFrames, data manipulation, cleaning, and aggregation |

### Module 4 — Data Visualization
| Topic | Description |
|-------|-------------|
| [Matplotlib](04-data-visualization/matplotlib/) | Foundational plotting library for static visualizations |
| [Seaborn](04-data-visualization/seaborn/) | Statistical data visualization built on Matplotlib |

## 🛠️ Tech Stack

- **Python 3.x**
- **Jupyter Notebook** — Interactive coding environment
- **NumPy** — Numerical computing
- **Pandas** — Data manipulation & analysis
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/itahir07/python-data-analysis.git
cd python-data-analysis

# Install dependencies
pip install numpy pandas matplotlib seaborn jupyter

# Launch Jupyter Notebook
jupyter notebook
```
